NIST SP 800-53 Gap Analysis Project

Federal Travel & Expense Authority (FTEA)
Project Description:

Conducted a structured gap analysis using the NIST SP 800-53 Moderate baseline to simulate a real-world GRC assessment for a federal agency. Reviewed security controls across key areas, including Access Control (AC), Identification and Authentication (IA), Configuration Management (CM), System and Communications Protection (SC), and Incident Response (IR).
Comparing the current implementation of controls against the expected requirements to identify gaps, weaknesses, and missing controls. Documented findings, assessed their impact on confidentiality, integrity, and availability, and provided risk-based recommendations to support compliance and strengthen the overall security posture.
Purpose of the Project 

The purpose of this project was to simulate a real-world GRC engagement and demonstrate my ability to apply a federal security framework, evaluate control effectiveness, identify gaps, and develop clear, actionable remediation strategies aligned with compliance standards. It also served as a hands-on way to practice real-world security and compliance work by actively comparing an organization’s security posture against NIST requirements rather than only studying them.

Tools Used:
Microsoft Excel for control tracking and analysis
NIST SP 800-53 control catalog

What I Learned:
This project taught me how to read and interpret NIST SP 800-53 controls and map them to real-world processes. It strengthened my ability to gather and evaluate evidence, think in terms of risk and impact, and clearly document gaps and recommendations. Additionally, it helped me understand how security frameworks translate into actual business operations and how to assess whether controls are effectively implemented in practice.
